{%- comment -%} Color-scheme bootstrap. Runs in , after the theme has loaded just-the-docs.js, so the scheme is applied through the theme's own jtd.setTheme() before the page paints — a dark-preferring visitor never sees a light flash. Precedence: a choice saved by the header toggle wins; otherwise the operating system's prefers-color-scheme decides, and keeps deciding while the visitor has made no explicit choice. Every comment inside the script below has to be a /* block */ comment. The theme's layout chain compresses each rendered page onto a single line, so a `//` comment would swallow the rest of the script and none of it would run. {%- endcomment -%}
