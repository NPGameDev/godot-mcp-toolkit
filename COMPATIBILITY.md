# Godot Version Compatibility

End-user compatibility documentation **ships with the addon**:
[`addons/godot_mcp_toolkit/docs/compatibility.md`](addons/godot_mcp_toolkit/docs/compatibility.md)
— version tiers, the per-tool compatibility and headless matrices, degraded
behavior by version, the C# (.NET) editor requirement, export stripping, and
data-format notes. That file is the single source; it travels with every
install and is reachable from the editor's Info/Help panel.

Contributor-facing compatibility engineering — the version-guard implementation
pattern, server-side version awareness, CI limitations, and future development
constraints — lives in
[CONTRIBUTING.md](CONTRIBUTING.md#compatibility-engineering).
