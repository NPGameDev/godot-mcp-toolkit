# Cross-Version Source Audit --- Maintenance Protocol

The static, source-grounded counterpart to the runtime sweep: it verifies that
every **version-dependent assumption** in the toolkit + server holds against the
real engine surface for each supported Godot version (**4.2--4.7**, GDScript
**and** .NET). Where the sweep exercises *paths that run*, this audits the
*surface as declared* --- including unexercised branches, silent signature drift,
and wrong guard thresholds that no runtime test hits.

This directory holds the **harness** (contributor-runnable) and the committed
**distilled compat map**. The per-version audit narratives live in the plan repo's
`SourceCodeAudits/` (they cite the compat map cross-repo).

## The four assumption-classes

1. **API existence** --- every engine method/class/enum the toolkit calls exists in version N.
2. **API signature** --- and has the same params/return in N.
3. **Version-guard correctness** --- every `is_at_least` / `has_method()` / `ClassDB.class_exists` / dynamic-dispatch guard gates the *right* threshold.
4. **Server version-logic + doc claims** --- every `min/max_godot_version`, version-tailored hint, `getGodotVersion()` branch, and `COMPATIBILITY.md` claim matches reality.

**Out of scope:** data-format compat (`.tscn`/`.tres`/binary drift) --- the toolkit
writes through `ResourceSaver`/`PackedScene`, so portability is engine-owned.

## Method (why the map is small and what it proves)

- **Spine:** per-version `extension_api.json`. It is machine-readable and *includes
  exposed editor classes* (`EditorInterface`/`EditorPlugin`/`EditorUndoRedoManager`/...).
- **Delta-diffing inverts the matrix:** most symbols are identical across all six
  versions. The map records **class presence for every class**, but a class *member*
  only when its presence differs from its owner class's lifetime **or** its signature
  drifts. Everything omitted is "present-and-stable wherever its class is present."
  This turns ~3.4k net-new methods into a few hundred genuinely-interesting deltas.
- **Signature identity uses Godot's ABI method `hash`.** A method whose primary hash
  changes is a signature drift; `hash_compatibility` (cumulative through 4.7) records
  the retained old bindings.
- **Guard-enumeration pass** (`enumerate_guards.sh`) is the class-3 complement:
  delta-diffing only re-checks guards on *changed* symbols, so a wrong threshold on a
  symbol that is **stable across all six versions** is invisible to it. The inverse
  pass enumerates *every* guard and resolves each gated symbol's true intro version.

### Durable facts established by this audit (keep these in mind)

- **Callable-API backward compatibility is total across 4.2--4.7:** *zero* regular
  (non-virtual) methods lost their old binding --- every callable-method signature
  drift is compat-preserved via `hash_compatibility`. Signature-drift risk is confined
  to **(a)** overridden **virtual** methods (`drift: "virtual-drift"` in the map) and
  **(b)** calling a method with a signature newer than the toolkit's min supported
  version. Existence risk (class-1) is the real surface: a symbol present only in newer
  versions (`note: "added-*"`).
- **.NET is a PascalCase projection of the same ClassDB.** The cross-diff confirms
  every manifest class has a C# type and every editor method a C# member (only the
  documented `Object`->`GodotObject` / `Thread`->`GodotThread` renames, acronym-casing
  `GLTF`->`Gltf`, dimension-casing `3d`->`3D`, and getter->property projections differ).
  The toolkit's duck-typed `Object.Call("snake_case")` path is unaffected by C# casing.

## Compat-map format

- **`presence`** --- 6-char string over `[4.2,4.3,4.4,4.5,4.6,4.7]`, `Y`=present `-`=absent.
- **`classes`** --- every class: `{present, api_type, inherits}`.
- **`member_deltas`** --- `Class.member -> {kind, present, owner_present, intro, note, sig|sig_by_version, drift?, is_virtual?}`. Absent member == stable within its class's lifetime.
- **`global_deltas`** --- `@util:` / `@genum:` / `@singleton:` symbols that vary across versions.
- **Convention:** to check an arbitrary `Class.member`: if the class is present in vN and the member is **not** in `member_deltas`, it is present-and-stable in vN. Use `lookup.py Class.member --version N` to cross-check against the raw dump.

## Running the harness

```bash
cd Validations/cross-version-audit/scripts
bash run_all.sh                 # full pipeline (FORCE=1 to redump)
# or individually:
bash dump_api.sh                # dump all editors (sequential; Godot NOT on PATH)
python build_compat_map.py      # rebuild committed compat map + delta report
python cross_diff_dotnet.py     # .NET reflect + cross-diff (4.2/4.5/4.6/4.7)
python filter_deltas.py --version 4.2      # what's absent/drifted in 4.2
python lookup.py EditorPlugin.add_dock     # point query
bash grep_delta_symbols.sh --version 4.2   # toolkit usage of 4.2-absent symbols
bash enumerate_guards.sh                   # every guard site (class-3/4)
```

Editor binaries are glob-discovered under `EDITORS_ROOT` (default
`C:/Users/nicol/Godot/Editors`); override `EDITORS_ROOT` / `DUMPROOT` / `TOOLKIT` /
`SERVER` via env. The C# reflect tool needs the .NET SDK (`dotnet`) --- first run
restores the `System.Reflection.MetadataLoadContext` package.

## When to update

Regenerate the compat map + re-run the affected audit pass whenever:

1. **A new Godot version is supported** --- add it (below), redump, rebuild the map,
   re-run all passes, and extend `COMPATIBILITY.md`.
2. **A tool adds/changes an engine API call** --- re-run `grep_delta_symbols.sh` and
   confirm any version-varying symbol it now touches has a correct guard.
3. **A version guard or threshold changes** --- re-run `enumerate_guards.sh` and
   resolve the changed site against the map (`lookup.py`).
4. **A server `min/max_godot_version` / version branch changes** --- re-check it
   against the map (class 4).
5. **`COMPATIBILITY.md` gains a claim** --- back-validate it against the map.

## Adding a new Godot version (e.g. 4.8)

1. Install the editor (and, if C# coverage is wanted, the mono editor) under `EDITORS_ROOT`.
2. Add a source worktree (see the plan repo's `memory/reference_godot_source_checkouts.md`).
3. Append the version to `VERSIONS` in `build_compat_map.py` and `filter_deltas.py`,
   to `STD_VERSIONS` (and `NET_VERSIONS` if mono) in `dump_api.sh`, and to
   `MONO_VERSIONS` in `cross_diff_dotnet.py` if a mono editor exists.
4. `FORCE=1 bash run_all.sh`, review `delta-report.md`'s new pairwise section, fix
   any finding, extend `COMPATIBILITY.md`, and bump the table above.

## Verification

- `run_all.sh` completes; `cross_diff_dotnet.py` prints **CLEAN**.
- `delta-report.md` shows **breaking-callable 0** at every boundary (any non-zero is a finding).
- Spot-check known-gated symbols resolve to the right intro column
  (`lookup.py EditorInterface.close_scene` -> 4.5; `EditorPlugin.add_dock` -> 4.6).
- The map covers all six versions; raw dumps are **not** committed (see `.gitignore`).
